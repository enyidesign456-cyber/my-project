# Meta Ads MCP 接入 Claude 指南

整理自 YouTube 教程 (dXIl87_V4dA)。目标:让 Claude 通过 Meta 官方 MCP 读取和操作 Meta 广告账户。

## 一、连接步骤

1. 登录 Claude(免费账号可以试,建议付费账号避免额度限制)。
2. 点输入框的 **+** → **Connectors** → **Add connector** → 选 **Custom connector**。
3. 名称填 `Meta Ads`,URL 填 Meta 官方 MCP 地址。
   - 视频转写里的地址听写不清,大概率是 `https://mcp.facebook.com/ads`。
   - **请以视频描述区给出的链接为准**,不要凭猜测填写。
4. 点 **Add**,会跳转到 Facebook 授权页,点 **Continue**。
5. 授权范围建议收紧:
   - Pages:选 **只授权当前选定的 Pages**,不要选"所有 Pages 及未来 Pages"。
   - Business features:同样只选需要的。
6. 看清列出的权限后点 **Save**。右上角显示 **Connected to Meta Ads** 即成功。

## 二、设置护栏(重要)

**+ → Connectors → Manage connectors → Meta Ads**,为每个工具设置权限:

- 默认:每次操作都要你批准(新手建议保持)。
- 可改成:自定义 / 无需批准 / 禁止。
- 建议:创建、复制、修改预算这类写操作始终要求批准,只读报表可以放宽。

## 三、示例提示词

**报表对比**
> 对比 Meta 广告账户最近 14 天与前 14 天按广告系列的单次潜在客户成本(CPL)。

**复制并加预算**
> 复制按 CPL 表现最好的广告组,并把日预算提高 5%。

视频中的结果:新广告组以暂停状态创建,日预算 $40 → $42,可在广告管理工具里核对后再启用。

**像素/转化事件诊断**
> 我的潜在客户转化事件触发正常吗?有没有红旗或问题?

视频中的结果:事件正常触发,但全部来自浏览器端,没有设置 Conversions API,Claude 给出了原因和修复建议。

## 四、其他提到的能力

创建广告系列、修复商品目录、诊断像素等。作者表示后续会有更深入的教程。

## 五、注意事项

- 先在小账号或测试账号上试用。
- 复制、创建的内容默认暂停,启用前自己检查。
- 随时可在 Facebook 的"业务集成"里撤销授权。
